# Дашина Игра

Спокойная головоломка про цвет: соберите плавный градиент из перемешанных плиток.

Игра работает прямо в браузере, ставится на экран «Домой» iPhone как приложение
и после первого запуска играется **без интернета**.

## Как играть

1. В начале уровня вы видите собранный градиент, затем плитки перемешиваются.
2. Коснитесь плитки, чтобы выбрать её, затем другой плитки: они поменяются местами.
   Повторное касание выбранной плитки снимает выбор.
3. Плитки с точкой в центре закреплены, их двигать нельзя. Это ориентиры: по ним
   видно, как должен идти цвет.
4. Уровень пройден, когда каждая плитка стоит на своём месте и цвет перетекает
   плавно по всему полю.

## Звёзды

У каждого уровня есть эталон: наименьшее возможное число обменов.

| Звёзды | Сколько ходов |
|--------|---------------|
| ★★★    | не больше эталона + 20% |
| ★★     | не больше эталона + 60% |
| ★      | больше |

Цель для трёх звёзд показана над полем справа. Уровень можно переиграть, чтобы
улучшить результат: засчитывается лучший.

## Наборы и уровни

- 10 наборов по 10 уровней, всего 100: **Рассвет, Океан, Лес, Пастель, Закат,
  Ночь, Лаванда, Осень, Лёд, Радуга**. Набор задаёт название, превью и фоновый
  оттенок экранов, а также характер палитр: в «Океане» они тянутся к сине-зелёным,
  в «Закате» к тёплым, в «Пастели» светлее и мягче.
- У каждого из 100 уровней своя палитра из четырёх угловых цветов. Её строит код
  (`getPalette` в `game.js`) по номеру уровня, одинаково у всех игроков: оттенки
  идут по золотому углу (137,5° × номер), цвета считаются в OKLCH в пределах
  L 0,55–0,9 и C 0,08–0,2 и переводятся в sRGB. Палитры любых двух уровней заметно
  различаются, соседних по номеру особенно сильно. Мини-градиент палитры виден
  на кнопке уровня.
- Поле плавно растёт от 4×5 на 1-м уровне до 9×13 на 100-м: от уровня к уровню
  добавляется не больше одного ряда или столбца.
- Закреплённых плиток становится меньше: на уровнях 1–20 это углы и часть краёв,
  на уровнях 21–90 только углы, на уровнях 91–100 только два противоположных угла.
- Разброс оттенков между углами плавно сужается от 140° на 1-м уровне до 35°
  на 100-м, поэтому на поздних уровнях соседние плитки различаются тоньше.
- Уровни внутри набора открываются по порядку.
- Следующий набор открывается, когда в текущем пройдено 7 уровней из 10.
- Раскладка уровня всегда одна и та же, у всех игроков одинаковая.

## Меню

- **Продолжить** открывает первый непройденный уровень.
- **Уровни** открывает список наборов: у каждого видны прогресс («6/10») и звёзды,
  вверху общее число звёзд. Внутри набора сетка из 10 уровней.

## Подсказки

- Подсказка ставит одну неверную плитку на её место. Это считается ходом.
- Если перед подсказкой выбрать неверную плитку, подсказка поставит именно её.
- Можно держать до 5 подсказок. Новая начисляется за каждые 5 впервые пройденных уровней.

## Управление

| Кнопка | Действие |
|--------|----------|
| Назад | к сетке уровней набора |
| Заново | вернуть стартовую раскладку и сбросить счётчик ходов |
| Подсказка | поставить одну плитку на место |
| Звук | включить или выключить звук (в главном меню) |

Звук синтезируется самой игрой. Он включается после первого касания экрана и
учитывает беззвучный режим iPhone: при выключенном звонке игра молчит.

## Сохранения

Прогресс, звёзды, подсказки и настройка звука хранятся на устройстве (в памяти
браузера). Регистрация не нужна, данные никуда не отправляются.

Ключи хранилища (`pereliv.save`, `pereliv.sound`) остались от прежнего названия
игры, чтобы прогресс не потерялся. Сохранение прежней версии (60 уровней) при первом
запуске переносится автоматически: пройденные уровни по порядку засчитываются как
уровни 1, 2, 3… с теми же звёздами, а подсказки остаются. Лучшие результаты при этом
сбрасываются: поля уровней стали другими.

## Файлы проекта

| Файл | Назначение |
|------|------------|
| `index.html` | страница игры |
| `style.css` | оформление |
| `game.js` | вся логика игры и звук |
| `sw.js` | Service Worker: офлайн-режим |
| `manifest.json` | описание приложения для установки на экран «Домой» |
| `icon-180.png`, `icon-512.png` | иконки |
| `make-icons.py` | скрипт, которым сгенерированы иконки (для игры не нужен) |

Без сборки и внешних библиотек: достаточно выложить файлы на любой статический хостинг,
например GitHub Pages.

## Выпуск обновления

После любого изменения файлов игры увеличьте версию кэша в `sw.js`:

```js
const CACHE = 'dasha-v4';   // → 'dasha-v5', затем 'dasha-v6' и так далее
```

Иначе у игроков останется старая сохранённая копия. Старые версии кэша, в том числе
`hue-v1` от прежнего названия, удаляются автоматически.

Иконки перерисовываются командой `python3 make-icons.py`.
